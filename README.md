# Dashboard de Clima

Aplicação web simples que consulta a previsão do tempo em tempo real
para qualquer cidade, usando a API do OpenWeather.

## Por que fiz esse projeto

Quis praticar consumo de API com JavaScript puro antes de partir pra frameworks.

## Tecnologias

- HTML5
- CSS3
- JavaScript (Fetch API)
- OpenWeather API

## Funcionalidades

- Busca de clima por nome de cidade
- Tratamento de erro para cidades inválidas
- Interface responsiva

## Como rodar localmente
1. Clone este Repositório
2. Abra o arquivo `index.html` no navegador
3. Gere sua própria chave em openweathermap.org e
   substitua no `script.js`
